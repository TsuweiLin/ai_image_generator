商品視覺所 — 網站原始碼

檔案說明
index.html：六個段落的網站內容與結構。
style.css：網站色彩、字型、排版與手機版樣式。

使用方式
解壓縮後，直接用瀏覽器開啟 index.html 即可查看。
請將 index.html 與 style.css 放在同一個資料夾。
使用任何文字或網頁編輯器即可修改，不需要安裝套件或編譯。
也可以將這兩個檔案交給網頁設計師，或放到支援靜態網站的主機。

備註
字型使用 Google Fonts，需要網路連線；離線時會自動使用系統字型。
案例區目前為預留內容，尚未加入實際商品圖片及銷售數據。
此原始碼備份不包含 Sites 帳號、權限或登入憑證。
修改下載的檔案不會自動更新已發佈的 Sites 網站。
